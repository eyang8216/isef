\subsection{Computational Pipeline}

A typical solver run follows the sequence summarized in Figure~\ref{fig:solver-flowchart}:
\begin{enumerate}
    \item Input physical and numerical parameters, including voltage, surface tension, domain size, and grid resolution.
    \item Build a two-dimensional axisymmetric $(r,z)$ grid.
    \item Construct electrode and boundary masks (or use immersed boundary representation).
    \item Assemble the sparse axisymmetric Laplace/Poisson matrix.
    \item Apply boundary conditions (staircase or immersed Dirichlet stencils) and solve $A\boldsymbol{\ph}=\boldsymbol{b}$.
    \item Reconstruct $\Er$, $\Ez$, and $\Emag$.
    \item Sample a candidate interface $R(z)$ from the ImplicitCone geometry.
    \item Compute interface normals, curvature, Maxwell pressure (from immersed $E_n$ reconstruction), capillary pressure, and residual.
    \item For immersed free-boundary optimization, project out the onset voltage $V_0^*$ per candidate.
    \item Optionally update the space-charge closure and repeat the Poisson solve until convergence.
    \item Return scalar diagnostics, field arrays and figure objects, and optionally a JSON summary of the run.
\end{enumerate}

\subsection{Consumer-Hardware Design}

The solver uses sparse matrices rather than dense matrices. For a grid of $n_r\times n_z$ nodes, the number of unknowns scales as $n_r n_z$, while the finite-difference operator has only a small number of nonzero stencil entries per row. This allows small-to-moderate grids to run quickly on a standard laptop.

\paragraph{Computational Performance.} Over the grid range measured here ($N=675$ to $85{,}073$ points) the wall-clock time of a single-threaded immersed Laplace solve is fitted by $\mathcal{O}(N^{0.99})$. A production-quality $121\times177$ grid (21,417 points) solves in approximately $0.46$~s on an Apple M4 laptop with 16~GB of memory. Sparse direct factorization is asymptotically superlinear in two dimensions, so this exponent should be read as an empirical description of the tested range rather than a bound.

\subsection{Interactive App}

A Streamlit application exposes basic parameters such as voltage, surface tension, electrode spacing, domain radius, grid resolution, and space-charge model. It is organized into four pages --- Overview, Solver, Verification and Documentation --- and returns scalar diagnostics together with visualizations of potential, electric-field magnitude, space-charge density, interface overlay, and residual profile. The Verification page provides two checks: a recovered-angle test that sweeps the cone half-angle and locates the flank-field exponent crossing, and an imposed-Taylor identity test that compares the projected onset amplitude against the analytic value. Both impose the analytical Taylor potential on the outer boundary. The app is a demonstration and analysis interface; \rev{the scientific contribution lies in comparing the reliability of angle observables rather than in the interface itself.}
