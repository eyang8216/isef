# 给教授的项目评审与执行方案

## 轻量级轴对称 Taylor 锥求解器：数值交叉验证与物理实验的两条路线

**提交目的：请教授进行技术评审、指出关键风险，并建议优先采用哪一条验证路线。**

**项目当前定位：** 一个经过局部数学测试、用于研究轴对称静电—毛细应力问题的轻量级计算框架。它目前不是完整的电喷雾流体动力学模拟器，也尚未完成物理实验验证。本文件把已有结果、尚未解决的问题，以及两条可执行的后续路线分开说明。

---

## 一、项目现在处于什么状态

目前的代码库已经完成了基础整理和第一轮数值审计。活动代码位于 `solver/`，测试位于 `solver/tests/`，论文源文件位于 `paper/paper_submission/`，审计材料位于 `audit/`。

当前自动化测试在记录的本地环境中为 **82 项通过**。新的四阶多项式制造解测试在四个逐步加密网格上给出了接近二阶的 L2 和 Linf 观测收敛阶，约为 2.01–2.03。这一结果只验证规则轴对称 Poisson 子问题，不等于完整 Taylor 锥自由边界模型已经收敛。

已覆盖的局部数学合同包括：轴对称轴线模板、柱面和直锥侧面的曲率、法向方向、预设压力与拟合压力的区别、压力投影、采样掩膜，以及部分边界优先级。

目前不能保留的强表述包括：已经预测真实起始电压、已经验证 cone–jet 转变、已经实现不受限制的自由边界求解器、已经证明相对于公平基准更快，以及图像处理流程已经达到小于一度误差的资格标准。

现有合成图像流程的实际重测没有通过原先写定的验收标准。一个名义 49.29°、长度 4 mm 的合成锥，在不同噪声水平下的角度误差约为 49.32°、40.58°、43.39° 和 66.81°，对应的轮廓 RMSE 约为 1.89、2.90、3.94 和 6.17 mm。因此，旧的图像准确率表不能作为论文结果使用，必须修复或删除相关结论。

## 二、应当先改进什么

### 1. 先完成耦合求解器的数值证据

规则制造解已经说明基础 Poisson 离散在一个规则问题上表现良好，但研究问题真正关心的是界面法向电场、曲率、应力残差、浸入边界处理和锥形状参数优化。下一步应建立分层验证：固定场误差、曲率误差、耦合残差、优化结果，再到敏感性研究。不能用第一层测试代替最后一层。

应至少运行四个网格等级，并分别改变外边界距离、尖端截断/圆钝化半径、界面采样窗口和初始优化参数。每个结果保存原始参数、运行命令、代码版本、误差、运行时间和失败状态。

### 2. 把压力和电压消元写成可检查的推导

对于线性静电场，若场幅度与电压成正比，则 Maxwell 压力与电压平方成正比。应明确写出残差中关于 `x=V²` 的最小二乘或非负最小二乘解、压力未知时的秩和退化情形，并在代码中用独立测试确认实现与推导一致。

如果启用阈值空间电荷闭合，场不再是简单的线性电压缩放，不能自动沿用 V² 标度。空间电荷模型应作为探索性分支，不能与无电荷线性结果混写。

### 3. 做可辨识性分析，而不是只报告一个最优点

应画出角度、尖端半径、压力和电压参数的目标函数景观，测试不同初值和边界，报告平坦区域、边界最优、失败收敛和多解情况。若角度稳定而电压不稳定，这本身是有价值的研究结论：模型可以稳健地诊断几何量，但不能从当前观测唯一确定物理电压。

### 4. 重新定义 “lightweight”

不能只因为代码短或运行快就称其为高效。需要记录硬件、网格规模、内存、字段求解时间、优化时间、总流程时间、重复运行变异，以及在相同误差水平下与一个透明基准的比较。如果没有公平加速，应使用“紧凑”“易访问”或“低计算负担”等更谨慎措辞。

### 5. 修复或撤回图像流程结论

图像验证必须是真正的像素到物理轮廓的闭环：生成图像、加入已知模糊和噪声、分割、轮廓提取、标定、坐标转换、独立拟合角度和轮廓误差。真值不能进入提取路径。应使用独立测试集，并报告失败次数、空白标定、边缘/背景、裁剪尖端、旋转、亚像素位移、非锥形轮廓和多连通区域。

如果修复成本超过项目时间，最诚实的方案是把图像处理降为实验计划中的待资格化工具，不在计算论文中宣称其准确率。

### 6. 完成针对一手文献的贡献矩阵

应比较静态导电液面、Taylor 理想锥、有限喷嘴平衡、降阶数值方法和相关幅度消元工作，逐项记录方程、边界、可表示几何、数值证据、计算代价和物理验证。最终贡献不能只是“使用 Python”“重现 49.29°”或“有很多单元测试”。更可信的贡献可能是一个经过量化的精度—成本—适用范围图，或一个清楚证明参数不可辨识的负结果。

## 三、路线 A：购买或获得 COMSOL，用作独立数值交叉验证

### 目标

使用 COMSOL 或等效的独立有限元软件，建立与当前模型尽可能匹配的静电—毛细压力问题，验证当前求解器能够代表它声称代表的有限域问题。COMSOL 不是物理真值，也不能替代实验；它的作用是减少“两个实现使用同一错误”的风险，并暴露边界、网格和尖端处理问题。

### A1. 先由教授审查比较问题

在购买前先冻结比较合同：轴对称几何、液体和气体介电常数、导体电势、外边界位置、界面形状是否固定、是否包含空间电荷、压力定义、法向方向、曲率定义、尖端截断和比较区域。两套模型必须使用相同单位和相同无量纲化。

第一轮不应比较自由界面或起始电压，而应比较一个固定、可复现的几何问题。建议从规则柱面/圆钝锥面和有限电极开始，再逐步进入浸入界面。

### A2. COMSOL 基准模型

建议建立二维轴对称静电模型，明确导体、电介质、气体域和外边界。导体电势设为固定值，外边界分别测试零电势和远场近似。输出界面上的法向电场、最大场、压力分布和积分量。尖端必须使用与 Python 模型一致的圆钝化或截断，不能把 COMSOL 的尖角结果当作可比较真值。

### A3. 网格和收敛

至少使用四个网格等级，尖端区域单独加密。比较场的 L2/Linf 误差、界面压力曲线、最大场和积分压力。记录自由度、内存、求解时间和容差。Python 结果应在相同物理问题和相同比较窗口上重采样，而不是直接比较不同网格节点。

### A4. 逐层交叉验证

第一层比较固定几何的电势场；第二层比较界面法向场；第三层比较 Maxwell 压力；第四层比较曲率—压力残差；第五层才考虑在双方都明确实现同一形状参数化时比较优化结果。若只有 COMSOL 有移动网格、结构耦合或更完整物理，必须把差异列为模型差异，而不是说 Python 代码被“验证”为真实物理。

### A5. 路线 A 的成功标准

成功不是要求两个软件给出完全相同的尖端数值，而是：在规则区和共同比较窗口内，误差随网格加密而下降；边界和尖端敏感性能够解释；残差符号和数量级一致；所有显著差异都能追溯到边界、曲率、材料或闭合差异。若结果不一致，应优先形成诊断报告，而不是调参让两条曲线重合。

### A6. 路线 A 的成本和风险

需要软件许可、COMSOL 建模和网格经验，以及教授或实验室对许可证和硬件的支持。最大风险是建立了一个看起来复杂但边界条件不匹配的“假独立基准”。因此，教授应在建模前审查比较合同。COMSOL 交叉验证可以显著增强数值可信度，但不能证明实验起始电压或完整 cone–jet 物理。

## 四、路线 B：进行实际受监督实验

### 目标

在合格实验室和有资质人员监督下，测量一个明确定义的可观测量，例如接近起始状态时的锥形界面轮廓和侧壁半角，并检验计算模型对该观测量的定性或定量预测。实验不是为了证明所有电喷雾物理都由当前模型解释。

### B1. 实验前冻结预测

在看到实验图像之前保存代码版本、依赖、网格、边界、流体参数来源、几何参数、压力处理、预测角度、预测轮廓和不确定度。禁止用实验图像反向调节模型参数后再声称预测。

### B2. 由实验室确定安全和设备边界

高电压、电荷、液体、尖锐电极、喷射和可能的气溶胶必须由主持实验室确定风险评估、屏蔽、接地、联锁、操作距离、废液处理和应急流程。学生不应独立决定高压器件、接线或运行条件。本计划不提供也不替代实验室安全操作规程。

### B3. 先做低风险光学和标定试验

在不施加危险工作电压前，完成相机、镜头、照明、背景、视场、标尺和坐标方向的标定。用已知几何物体验证像素到长度的转换、边缘方向、轴位置和轮廓拟合。空白标定和失败图像必须保留。

### B4. 预注册可观测量和排除标准

主响应变量建议为侧壁半角和界面轮廓；起始电压只作为次级响应，并用预先定义的操作状态标签记录，例如无明显变形、变形液面、锥状不稳定状态、稳定锥/锥射流状态和断裂/喷雾状态。不能把肉眼标签自动等同于理论 onset。

### B5. 重复和不确定度

每个预定条件应有独立重复，记录电压、流量或液体供给状态、时间、温度、湿度、图像曝光、焦距、标定文件和排除理由。相邻视频帧不是独立实验。应区分随机误差、标定系统误差、边缘定位误差和条件漂移。

### B6. 模型—数据比较

先以冻结预测比较轮廓和角度，再进行误差预算和敏感性分析。若数据支持角度但不支持电压，应分别报告；若实验状态不稳定或无法达到预定义条件，应将结果写成可行性/限制报告而非失败的物理预测。

### B7. 路线 B 的成功标准

实验路线成功的最低标准是：安全和审批完成；标定可追溯；观测量事先定义；有足够的独立重复；排除标准透明；图像分析经过独立合成测试或明确标记为未资格化；模型和数据在未调参的条件下比较。即使最终不吻合，只要差异可重复且解释清楚，也可能形成有价值的限制性结果。

## 五、两条路线如何选择

如果目前最重要的是判断 Python 求解器是否正确，优先路线 A。它最快地回答边界条件、场计算、曲率和残差是否实现一致，也最适合在实验前发现数值错误。

如果教授和实验室已经具备合适的设备、审批路径和高压操作能力，且研究重点是物理可观测量，路线 B 的科学价值更高，但时间、风险和不可控因素也明显更大。实验不应在图像管线尚未通过标定前开始。

最稳健的顺序是：先完成 D–F 的 Python 数值审计；随后用一个有限、固定几何问题做 COMSOL 交叉验证；并行修复 G 的图像流程；教授确认比较合同后，再决定是否进行受监督物理实验。若许可证不可得，可使用公开、可复现的有限元基准，但必须把“独立性”程度写清楚。

## 六、给教授的具体评审问题

1. 当前模型的最小可发表问题应定义为固定有限域应力残差、受限锥族优化，还是其他更合适的对象？
2. 在没有完整流体动力学和空间电荷输运的情况下，哪些几何或电压表述是可接受的？
3. COMSOL 交叉验证应首先比较哪些物理量和边界设置？
4. 哪些网格、外边界和尖端敏感性足以支持数值精度声明？
5. 当前优化结果是否具有可辨识性，还是应把结果转写为限制性诊断？
6. 图像流程失败后，是否值得修复，还是应暂时删除图像准确率主张？
7. 若进行实验，实验室能够提供哪些安全监督、设备和标定支持？
8. 从 ISEF 研究贡献角度，最值得集中资源证明的是精度—成本优势、可辨识性结论，还是与独立有限元结果的一致性？

## 七、建议的执行顺序和停止点

第一步是修正论文中的旧测试数量和旧图像准确率表述，建立当前结果清单。第二步是完成耦合求解器的网格、域、尖端、采样和优化敏感性研究。第三步是完成线性电压/压力消元推导及目标函数和可辨识性分析。第四步是建立一个固定几何的独立有限元比较；如果无法取得 COMSOL，则明确记录可复现替代基准。第五步是修复图像管线或从论文中撤回其准确率结论。第六步是完成一手文献贡献矩阵。第七步是依据结果重写论文、生成所有图表并编译。第八步才是向实验室提交受监督可行性申请。

在真实实验所需的安全审批、光学标定、液体和电极实测参数、稳定工作状态及独立物理重复出现之前，项目的正确状态应写为：

> **计算工作已部分验证；完整耦合模型和物理实验仍待交叉验证与主持实验室批准。**

这不是项目失败，而是对证据边界的准确描述。若路线 A 显示模型在共同问题上稳定且具有可量化成本优势，项目可以恢复更强的数值贡献；若路线 B 进一步支持角度和轮廓，则可以增加物理验证层；若任一路线揭示电压不可辨识或边界高度敏感，则应把该发现作为核心限制性结果，而不是隐藏它。
